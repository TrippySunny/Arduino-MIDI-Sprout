# Arduino-MIDI-Sprout

Hello, this repository will contain all the information needed to replicate this system: Arduino components, Arduino code, and applications for reading the signal. How to make beautiful music out of this will not be discussed here, you yourself must do this according to your taste and preferences. If you don't want to spend money on expensive devices and are willing to do it all yourself for a fraction of the cost, then this repository is for you.

Programs you will need:
Arduino IDE - https://www.arduino.cc/en/software
Hairless MIDI - https://projectgus.github.io/hairless-midiserial/
loopMIDI - https://www.tobias-erichsen.de/software/loopmidi.html
FL Studio - https://www.image-line.com/ (or any other music editor)
